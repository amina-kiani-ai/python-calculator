Python Calculator 

A beginner-friendly calculator project built using Python and Tkinter.

Features

- Addition
- Subtraction
- Multiplication
- Division
- Division by zero handling
- Graphical User Interface (GUI)
- Orange calculator buttons
- Backspace and Clear functionality
- Safe mathematical expression evaluation

Technologies Used

- Python
- Tkinter
- AST (Abstract Syntax Trees)

Project Files

- "calculator.py" - Command-line calculator
- "gui_calculator.py" - Graphical calculator

How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Run "gui_calculator.py" to open the graphical calculator.
4. Run "calculator.py" to use the command-line calculator.
